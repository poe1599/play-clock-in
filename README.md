# play-clock-in

# 自動打卡程式

## 功能說明

這是一個自動化打卡程式，可以根據環境變數設定自動執行打卡作業。

## 檔案結構

- `main.js` - 主程式檔案
- `select-date.html` - 日期選擇頁面（用於產生打卡日期）
- `.env` - 環境變數設定檔（包含使用者資料和時間範圍）
- `.env.example` - 環境變數設定檔範例
- `selected-dates.json` - 打卡日期檔案（由日期選擇頁面產生）
- `logs/` - 執行記錄資料夾

## 設定檔說明

### 環境變數設定 (.env)

程式改用環境變數方式管理設定，更加安全且符合業界標準。請複製 `.env.example` 檔案為 `.env` 並填入實際資訊：

```bash
# 打卡系統設定

# 打卡網址
CLOCK_IN_URL=http://打卡網址

# 使用者資料
USER_ID=你的員工編號
USER_PASSWORD=你的密碼

# 打卡時間範圍 (格式: HH:mm)
TIME_RANGE_START=08:30
TIME_RANGE_END=09:00
```

**環境變數說明：**

- `CLOCK_IN_URL`: 打卡系統的網址
- `USER_ID`: 您的員工編號
- `USER_PASSWORD`: 您的登入密碼
- `TIME_RANGE_START`: 打卡時間範圍的開始時間
- `TIME_RANGE_END`: 打卡時間範圍的結束時間

> **⚠️ 重要提醒**: `.env` 檔案包含敏感資訊，已設定於 `.gitignore` 中，不會被版本控制系統追蹤。

### selected-dates.json 檔案

程式會直接讀取根目錄下的 `selected-dates.json` 檔案。

### 日期選擇頁面 (select-date.html)

為了方便選擇打卡日期，專案提供了視覺化的日期選擇工具：

**功能特色：**

- 📅 **直覺式日曆介面**：以月曆形式顯示當月日期
- 🖱️ **點擊選擇**：點擊日期即可選擇，再次點擊取消選擇
- 🔄 **月份切換**：支援切換到上個月或回到當月
- 👁️ **即時預覽**：即時顯示已選日期和 JSON 格式預覽
- 💾 **一鍵匯出**：產生 `selected-dates.json` 檔案供主程式使用

**使用方法：**

1. 在瀏覽器中開啟 `select-date.html`
2. 點擊要打卡的日期（已選日期會呈現藍色高亮）
3. 使用「上個月」/「本月」按鈕切換月份（如需選擇其他月份）
4. 確認選擇後，點擊「匯出 JSON 檔案」按鈕
5. 下載的 `selected-dates.json` 檔案會自動放置在下載資料夾
6. 將此檔案複製到專案根目錄即可

## 使用方式

### 第一步：準備環境

1. 確保已安裝 Node.js (版本 >= 22.12.0)
2. 安裝相依套件：
   ```bash
   npm install
   ```

### 第二步：設定環境變數

1. 複製環境變數範例檔案：
   ```bash
   cp .env.example .env
   ```
2. 編輯 `.env` 檔案，填入你的實際資訊：
   - 打卡網址 (`CLOCK_IN_URL`)
   - 員工編號 (`USER_ID`)
   - 登入密碼 (`USER_PASSWORD`)
   - 時間範圍 (`TIME_RANGE_START`, `TIME_RANGE_END`)

### 第三步：選擇打卡日期

1. 在瀏覽器中開啟 `select-date.html` 日期選擇頁面
2. 使用直覺式日曆介面選擇需要打卡的日期
3. 點擊「匯出 JSON 檔案」下載 `selected-dates.json`
4. 將下載的檔案放置到專案根目錄

### 第四步：執行自動打卡

1. 執行程式：
   ```bash
   npm start
   ```
   或
   ```bash
   node main.js
   ```

> **💡 建議工作流程**：先使用 `select-date.html` 選定打卡日期，再執行主程式進行自動打卡作業。

## 功能特色

- **環境變數管理**: 使用 `.env` 檔案管理敏感設定，符合 12-factor app 原則
- **隨機時間**: 在設定的時間範圍內隨機產生打卡時間
- **安全性增強**: 敏感資訊（網址、帳號密碼）透過環境變數管理，不會暴露在版本控制中
- **結果記錄**: 在 `logs` 資料夾產生詳細的執行記錄
- **錯誤處理**: 完整的錯誤處理機制
- **進度顯示**: 即時顯示執行進度和結果

## 注意事項

- 請確保網路連線正常
- 首次執行時瀏覽器會下載 Playwright 所需的瀏覽器檔案
- 程式執行時會開啟瀏覽器視窗，請勿手動操作
- 執行結果會儲存在 `logs` 資料夾中
- 請妥善保管 `.env` 檔案，不要分享給他人

## 安全性

- **環境變數管理**: 使用 `.env` 檔案管理敏感設定，相比 JSON 檔案更安全
- **版本控制排除**: `.env` 檔案已加入 `.gitignore`，避免敏感資訊外洩
- **範例檔案**: 提供 `.env.example` 檔案作為設定範本，不包含真實資料
- 建議定期檢查 git 狀態，確保敏感檔案未被意外提交
